# Sample Data Folder

Place your anonymized/public sample files here so **Load Sample Case** in `/analysis` uses real data automatically:

- `sample_mri.nii.gz` — Real 3D brain MRI scan (`.nii.gz`, recommended `<= 15 MB`)
- `sample_speech.wav` (or `sample_speech.mp3` / `sample_speech.webm`) — Real speech recording (`<= 2 MB`, under 2 minutes)

If either file is not present yet, the app automatically falls back to the built-in illustrative PNG and transcript.
